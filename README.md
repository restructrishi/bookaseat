This is a simple web application that allows users to change the background color of the page dynamically. It's built using HTML, CSS, and JavaScript.

Features
Change the background color to a random color.
Predefined color options for easy selection.
Minimalistic and responsive design.
Technologies Used
HTML: Structure of the web page.
CSS: Styling and layout.
JavaScript: Functionality for switching background colors.

The index.html file contains the structure of the application, including buttons for color switching.

CSS
The style.css file adds styling for buttons, layout, and background transitions.

JavaScript
The script.js file contains the functionality to switch background colors, including a random color generator.

Example Usage
Click the "Random Color" button to change the background to a random color.
Select a predefined color from the options provided.
